Where it comes from

The source is NASA Physical Science Informatics, released as CC0. The 22 accessions in Combustion Science hold 7,463 files; IGNIS reads the experimental test tables and the reports that document pressure where a table leaves it out.

The raw files are 5.4 GB and stay out of the repository. index.json lists each one, and the rebuild steps regenerate every number on this page from them.

Each table is mapped by an explicit column spec: three pressure units, two oxygen conventions, free-text values and a literal 0 used for missing data. Rows set aside are counted by cause on the project page.

Data: NASA Physical Science Informatics (PSI), CC0. Normalized data released under CC0 as well. No NASA logo or endorsement is implied.
